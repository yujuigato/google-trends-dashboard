Background

這個系統在解決什麼問題？

業務與行銷團隊需要掌握市場熱點，但 Google Trends 的原始介面難以做跨週比較與主題聚合分析。

😣 過去的痛點

  • Google Trends 介面難以跨週比較趨勢變化
  • 熱搜中混雜娛樂、新聞，難以聚焦商業議題
  • 無法自動識別「新興崛起」vs「持續上升」的關鍵字
  • 主題聚合需要人工整理，無法即時更新

✅ 系統如何解決

  • Selenium 每週自動爬取，商業白名單過濾雜訊
  • 自動分類趨勢（新興★ / 上升↑ / 持平→ / 下降↓）
  • 10 大商業主題自動聚合（AI 科技、半導體、地緣衝突等）
  • GitHub Pages 自動發布，隨時可瀏覽最新儀表板

Features

儀表板功能

功能說明
關鍵字視角Top 排名清單、類別篩選、趨勢分類標籤、時間區間選擇
主題視角10 大商業主題聚合，語意相關關鍵字自動歸類
Sparkline 圖每個關鍵字的月份趨勢微折線圖，一眼掌握走向
首現標記標示本週首次出現的新興關鍵字
URL 狀態記憶篩選條件寫入 URL，可直接分享特定視角
CSV 匯出一鍵匯出當前篩選結果為 CSV
